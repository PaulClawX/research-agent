# Paper Writing Skills

这个分组专门解决“论文文字怎么改得更像论文”。

## 适用任务

- 改 abstract
- 改 introduction
- 改 method
- 改 experiments
- 改 conclusion
- 改 rebuttal

## 可用 Skill

### `polish-paper`

适合已经是英文草稿，但表达还不够紧、不够清晰、不够 conference-ready 的情况。

特别适合：

- section polishing
- conference-style rewrites
- rebuttal cleanup
- issue-first review plus rewrite

## 推荐阅读顺序

1. 先看 `polish-paper/SKILL.md`
2. 再看 `polish-paper/references/prompt-templates.md`
3. 最后根据你的 section 类型挑模板
