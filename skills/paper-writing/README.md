# Paper Writing Skills

This group contains skills for academic writing improvement.

## Available Skills

### `polish-paper`

Use this when the draft is already in English and the goal is better academic writing quality without changing the science.

Best for:

- section polishing
- conference-style rewrites
- rebuttal cleanup
- issue-first review plus rewrite

### `polish-paper-bilingual`

Use this when the draft is Chinese, mixed-language, or needs bilingual output.

Best for:

- Chinese academic polishing
- Chinese-to-English paper rewriting
- English-to-Chinese academic rewriting
- side-by-side bilingual output
